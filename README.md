Репозиторий Snake (Magnetic)
Описание
Snake (Magnetic) – это набор консольных реализаций классической игры «Змейка» с уникальной механикой магнитного притяжения. Игрок управляет змейкой, которая автоматически притягивается к еде, когда находится в радиусе действия (3 клетки). Это добавляет новый уровень сложности и стратегии: нужно планировать маршрут, учитывая, что змейка будет «тянуться» к еде.

Особенности игры
Классическое управление: стрелки (↑ ↓ ← →) для направления движения.

Магнитный эффект: когда голова змейки находится в радиусе 3 клеток от еды, направление автоматически корректируется в сторону еды (приоритет у игрока).

Счет и уровень: скорость увеличивается с каждыми 5 съеденными яблоками.

Стены: при столкновении со стеной или собственным телом игра заканчивается.

Рекорд: сохраняется в локальный файл (snake_record.txt).

Пауза: клавиша P или Space.

Цветной вывод в терминале (ANSI-коды) для лучшей визуализации.

Интерактивный режим – игра запускается сразу и ждет ввода.

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения. Никаких внешних зависимостей не требуется (только стандартные библиотеки).

Язык	Команда запуска
Python	python snake.py
JavaScript	node snake.js
TypeScript	ts-node snake.ts
Go	go run snake.go
Java	javac Snake.java && java Snake
C#	csc Snake.cs && Snake.exe
PHP	php snake.php
Ruby	ruby snake.rb
Управление
↑ – вверх

↓ – вниз

← – влево

→ – вправо

P или Space – пауза / продолжение

Q – выход (в некоторых версиях)

Магнитный эффект
Когда голова змейки находится на расстоянии ≤ 3 клеток (по манхэттенскому расстоянию) от еды, змейка автоматически поворачивает в направлении еды. Приоритет всегда за игроком: если игрок нажал клавишу, то его направление имеет приоритет над магнитом. Это позволяет сохранять контроль, но требует быстрой реакции.
